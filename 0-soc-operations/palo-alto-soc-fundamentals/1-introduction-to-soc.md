# Security Operations Fundamentals — Resumo

## 1. Security Landscape
Security Operations (SecOps) surgiu como resposta ao aumento das ameaças cibernéticas.  
As organizações estão deixando de usar **soluções isoladas e processos improvisados**, migrando para **arquiteturas de segurança unificadas com equipes dedicadas de SecOps**.

### Principais Riscos
- Violação catastrófica de dados (data breach)
- Exfiltração de dados
- Grandes perdas financeiras
- Danos à reputação da empresa
- Perda de clientes atuais e futuros
- Problemas legais e regulatórios
- Necessidade de compensação a clientes

---

## 2. Security Operations (SecOps)

### O que é
SecOps é a função responsável por **identificar, investigar e mitigar ameaças**, além de **melhorar continuamente os processos de segurança**.

### Objetivos principais
- Reduzir o número de alertas que chegam ao SOC
- Permitir investigação rápida de ameaças
- Diminuir o tempo de contenção de incidentes

### O que o time SecOps monitora
- Redes
- Servidores
- Endpoints
- Bancos de dados
- Aplicações
- Websites
- Sistemas locais ou remotos

### Missão do SecOps
Detectar, analisar e responder a incidentes de segurança usando:
- Tecnologias de segurança
- Processos estruturados
- Colaboração entre equipes

### SecOps como colaboração
SecOps integra:
- **Times de segurança**
- **Times de operações**

Protegendo:
- Usuários (internos, parceiros e clientes)
- Sistemas
- Dados da organização

Objetivo final: **melhorar a postura de segurança da empresa** e tornar **segurança uma responsabilidade compartilhada**.

---

## 3. Processo de Proteção do SecOps

1. **Identify**  
   Identificar um alerta como potencialmente malicioso e abrir um incidente.

2. **Investigate**  
   Analisar o alerta para entender a ameaça.

3. **Mitigate**  
   Conter e remediar o incidente.

4. **Continuously Improve**  
   Melhorar processos e ferramentas com base nos incidentes analisados.

---

## 4. Security Orchestration

Security Orchestration é o método de **conectar diferentes tecnologias de segurança** através de **workflows automatizados** para melhorar a resposta a incidentes.

### Objetivo
Permitir que equipes de segurança respondam a incidentes **de forma mais rápida, padronizada e eficiente**.

---

## 5. Automação em Security Operations

Automação busca **eliminar processos manuais** no SecOps.

Benefícios:
- Análise de dados mais rápida
- Respostas consistentes
- Redução do trabalho manual
- Melhor capacidade de investigação
- Resposta e mitigação mais eficientes

---

## 6. Terminologia Importante

### Security Automation
Execução automática de tarefas de segurança usando respostas baseadas em máquinas para garantir consistência.

### Playbooks
Fluxos de trabalho automatizados que definem **passo a passo como responder a incidentes**.

### Integration
Conexão entre diferentes ferramentas de segurança.

### Ingestion
Processo de **coleta e ingestão de dados de segurança** vindos de diversas fontes.

---

## 7. Componentes da Security Orchestration

A arquitetura de orquestração inclui diversos componentes e tecnologias que:

- Integram ferramentas de segurança
- Automatizam processos
- Permitem resposta coordenada a incidentes

Esses sistemas normalmente são **gerenciados por especialistas ou administradores responsáveis pela plataforma de automação**.

Todos os componentes trabalham juntos para formar **a base da automação de segurança dentro da empresa**.
